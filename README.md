# QRForge

Generator kode QR kustom (warna, ukuran, teks/URL) yang bisa langsung diunduh sebagai gambar PNG.

## Fitur
- Masukkan teks atau URL
- Pilih warna foreground dan background
- Atur ukuran (px)
- Generate dan unduh sebagai PNG
- Responsif

## Menjalankan
Buka `index.html` di browser, atau:
```bash
python3 -m http.server 8080
```
